# split-calc

三井住友カードとJCBの「あとから分割」について、利用金額と分割回数から毎月の支払金額・元金・手数料・残元金を表示する Python CLI です。外部パッケージは使いません。

## 環境構築

Python 3.12と[uv](https://docs.astral.sh/uv/)を使用します。uvをインストールしたうえで、リポジトリのルートで環境を同期してください。

```console
uv sync
```

uvは `.python-version` に指定したPython 3.12を選択し、必要に応じてPython本体を取得して `.venv` を作成します。生成される `.venv` はGitの管理対象外です。

コミットメッセージの検査を有効にするため、初回のみpre-commitの`commit-msg`フックをインストールしてください。

```console
uvx pre-commit install --hook-type commit-msg
```

以後のコミットでは、`feat(cli): add monthly installment breakdown`のようなConventional Commits形式が必須になります。使用できるtypeは`feat`, `fix`, `docs`, `test`, `refactor`, `perf`, `build`, `ci`, `chore`, `style`, `revert`です。破壊的変更ではsubjectの`!`と`BREAKING CHANGE:` footerの両方が必要です。

## 使い方

どちらの対話入力も `Ctrl+C` で中断できます。

### 単発の分割払いをシミュレーションする

```console
uv run split_calc.py 60000 3
```

カード会社は `--card` で指定します。省略時は対話形式で入力でき、空のままEnterを押すと三井住友カード（`smbc`）になります。

```console
uv run split_calc.py 100000 10 --card jcb
```

JCBの実質年率は既定で15.00%です。カードに適用される年率を指定する場合は `--annual-rate` を使います。JCBを対話形式で選び、`--annual-rate` を省略した場合は年率も対話形式で入力できます。

```console
uv run split_calc.py 100000 10 --card jcb --annual-rate 18.00
```

引数を省略すると対話形式で入力できます。

```console
uv run split_calc.py
支払金額（円）: 60000
分割回数: 3
カード会社（smbc/jcb） [smbc]:
```

JCBと年率を対話形式で指定する例です。

```console
uv run split_calc.py
支払金額（円）: 100000
分割回数: 10
カード会社（smbc/jcb） [smbc]: jcb
実質年率（%） [15.00]: 18.00
```

申込月を指定する場合は `--start YYYY-MM` を使います。第1回はその翌月として表示されます。

```console
uv run split_calc.py 60000 3 --start 2026-08
```

三井住友カードの対応回数は `3, 4, 5, 6, 10, 12, 15, 18, 20, 24, 30, 36, 40, 42, 48, 50, 54, 60` 回です。JCBは3～24回の各回と `30, 36, 42, 48, 54, 60` 回に対応します。利用金額は1,000円以上です。

### 複数の支払いから繰り上げ返済順を最適化する

対話形式で入力する場合は `--optimize` を指定します。毎月の積立額を入力した後、
各支払いのカード会社・年率・名前・利用金額・分割回数・申込月を一件ずつ入力します。
入力値に誤りがあれば、その項目でエラーを表示して再入力できます。各支払いの入力後には
内容確認があり、確定すると同じ内容を次回から直接指定できる `--payment` 引数が表示されます。
一件の確定後、次の支払いを追加するか確認されます。角括弧内の既定値は、何も入力せず
Enterを押すと使用されます。

内容確認で `n` または空Enterを選ぶと、その支払いを破棄して計算に進むか確認されます。
そこで `y` を選ぶと、それまでに確定した支払いだけで計算を開始します。`n` または
空Enterを選ぶと、同じ支払いを先頭から入力し直します。確定済みの支払いがまだない場合は
破棄して計算できないため、再入力になります。

以前表示された `--payment` の引数部分がある場合は、各支払いの先頭で貼り付けると
項目別の入力を省略できます。`--payment` 自体や外側の引用符は入力しません。

```console
uv run split_calc.py --optimize
毎月の繰り上げ返済積立額（円）: 30000
積立開始月（YYYY-MM、省略時は最初の支払月）: 2026-09

--- 支払い 1 ---
--payment の引数部分（個別入力は空Enter）:
カード会社（smbc/jcb） [smbc]: jcb
実質年率（%） [15.00]: 18.00
支払い名 [支払い1]: 家電
利用金額（円）: 300000
分割回数: 24
申込月（YYYY-MM） [2026-08]: 2026-08
この内容でよろしいですか？ [y/N]: y

--payment '家電:jcb:300000:24:18.00:2026-08'

支払いを追加しますか？ [y/N]: y

--- 支払い 2 ---
--payment の引数部分（個別入力は空Enter）: 家具:smbc:200000:20::2026-08
入力内容
カード会社: 三井住友カード
支払い名: 家具
利用金額: 200,000円 / 分割回数: 20回
申込月: 2026-08
この内容でよろしいですか？ [y/N]: y

--payment '家具:smbc:200000:20::2026-08'

支払いを追加しますか？ [y/N]: n
```

項目別入力で2件目を追加する場合は、引数部分を空にして続けます。

```console
--- 支払い 2 ---
--payment の引数部分（個別入力は空Enter）:
カード会社（smbc/jcb） [smbc]:
支払い名 [支払い2]: 家具
利用金額（円）: 200000
分割回数: 20
申込月（YYYY-MM） [2026-08]: 2026-08
この内容でよろしいですか？ [y/N]: y

--payment '家具:smbc:200000:20::2026-08'

支払いを追加しますか？ [y/N]: n
```

コマンドライン引数だけで入力する場合は、`--payment` を支払いの数だけ指定します。

`--payment` を支払いの数だけ指定し、通常の月々の支払いとは別に貯める金額を
`--monthly-saving` で指定します。返済順の候補を探索し、予定手数料が最も少なく
なる順序と繰り上げ返済月を表示します。

```console
uv run split_calc.py \
  --payment 家電:jcb:300000:24:18.00:2026-08 \
  --payment 家具:smbc:200000:20::2026-08 \
  --monthly-saving 30000 \
  --saving-start 2026-09
```

支払いの書式は
`名前:カード会社:利用金額:分割回数[:JCB年率[:申込月]]` です。年率を省略して
申込月を指定するときは、上の `smbc` の例のように年率部分を空にします。比較は
最大12件までです。返済順を一件ずつ探索し、途中までの手数料が既知の最良結果以上に
なった枝と、同じ状態へより高い手数料で到達した枝を打ち切ります。同じ手数料になる
順序が複数ある場合は入力順を優先します。

積立開始月は対話入力または `--saving-start YYYY-MM` で指定できます。省略時は、
入力した支払いのうち最初の支払月から積み立てます。積立開始月より前に発生する通常返済も
残元金と手数料へ反映します。

毎月の積立と同月の通常支払いを行った後、積立残高が対象の残元金以上になれば、
残元金を一括返済するものとして計算します。通常の月々の支払額は積立額に含みません。
積立は1か月につき1行で表示し、繰り上げ返済は同じ月の別行に出金として表示します。
左端の「回」は積立回数で、最初に毎月の積立額を加算する月を1回目として数えます。
積立・繰り上げ返済後の積立残高を追える、簡易的な帳簿形式です。`返済` には
その月の通常分割返済額の合計を表示し、繰り上げ返済額は含めません。

```text
回  月       摘要                     返済         積立     繰上返済     積立残高
--  -------  ----------------  -----------  -----------  -----------  -----------
 5  2027-01  積立                 26,616円     30,000円  ***********    150,000円
    2027-01  繰上返済（家具）  ***********  ***********    150,000円          0円
```

三井住友カードなどの実際の繰り上げ精算額は所定の方法で再計算されるため、この結果は
予定表の残元金と以後の手数料を使った比較用の概算です。実行前にカード会社へ精算額を
確認してください。

## 計算方法

- 三井住友カードは2025年4月1日改定後の公式の実質年率と「利用金額100円当たりの手数料」を使用します。
- JCBは指定した実質年率（既定15.00%、指定可能範囲7.92～18.00%）を前提に元利均等払いで計算します。初回手数料は締切翌日の16日から翌月10日までを年365日で日割りし、2回目以降は指定年率の12分の1に相当する月利で計算します。
- 総手数料は `利用金額 × 100円当たりの手数料 ÷ 100` の1円未満を切り捨てます。
- 支払総額を回数で均等に分け、1円未満の端数は公式案内どおり初回に加えます。
- 三井住友カードの月別元金も回数で均等に分け、端数を初回に加えます。各回の支払額との差を月別手数料として表示します。
- JCBの月別手数料は1円未満を切り捨て、最終回は残元金を全額支払うよう調整します。

三井住友カードの月別内訳は、定額分割方式（総額均等割）に基づく表示です。繰り上げ返済時の精算額は、78分法またはそれに準ずる所定の方法で計算されるため、この残元金とは異なります。一部カード・加盟店やボーナス併用払いでは条件が異なる場合があります。

JCBの手数料率はカードの種類により異なります。本ツールのJCBモードは毎月15日締め・翌月10日払いとして計算します。金融機関休業日やカード固有の条件などにより、実際の請求額とは異なる場合があります。

公式情報: [三井住友カード「あとから分割」](https://www.smbc-card.com/mem/revo/atokarabunkatsu.jsp)

公式情報: [JCB「ショッピング利用後分割払い」](https://www.jcb.co.jp/payment/installment/later/)、[JCBショッピング分割払い「ご利用にあたって」](https://www.jcb.co.jp/payment/pop/kappan-goriyou.html)
