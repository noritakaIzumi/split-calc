# split-calc

三井住友カードの「あとから分割」について、利用金額と分割回数から毎月の支払金額・元金・手数料・残元金を表示する Python CLI です。外部パッケージは使いません。

## 使い方

```console
python split_calc.py 60000 3
```

引数を省略すると対話形式で入力できます。

```console
python split_calc.py
支払金額（円）: 60000
分割回数: 3
```

申込月を指定する場合は `--start YYYY-MM` を使います。第1回はその翌月として表示されます。

```console
python split_calc.py 60000 3 --start 2026-08
```

対応回数は `3, 4, 5, 6, 10, 12, 15, 18, 20, 24, 30, 36, 40, 42, 48, 50, 54, 60` 回、利用金額は1,000円以上です。

## 計算方法

- 2025年4月1日改定後の公式の実質年率と「利用金額100円当たりの手数料」を使用します。
- 総手数料は `利用金額 × 100円当たりの手数料 ÷ 100` の1円未満を切り捨てます。
- 支払総額を回数で均等に分け、1円未満の端数は公式案内どおり初回に加えます。
- 月別手数料は残元金と実質年率から概算し、総手数料との差を最終回で調整します。

三井住友カードが公開しているのは総手数料と月々の支払額であり、通常の分割払いにおける月別の元金・手数料内訳は公式の請求明細ではありません。本ツールの月別内訳は参考値です。一部カード・加盟店やボーナス併用払いでは条件が異なる場合があります。

公式情報: [三井住友カード「あとから分割」](https://www.smbc-card.com/mem/revo/atokarabunkatsu.jsp)
